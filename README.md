# Worldfront

A tiny Godot 4 prototype for a future real-time strategy game.

## Current prototype
- One small green land map.
- Two capitals: Red and Blue.
- Five civilians for each team, drawn as coloured balls with little arms and legs.
- Civilians automatically walk to trees and rocks, gather wood or stone, and return it to their own capital.
- Resource totals are shown at the top of the screen.
- No combat, borders, or world map yet.

## Run it
1. Install Godot 4.3 or newer.
2. Download or clone this repository.
3. In Godot, choose **Import** and select the project.godot file.
4. Open the project and press **F6** or **F5** to run the game.

This is an early prototype made with built-in drawing only; it does not need external art assets.
